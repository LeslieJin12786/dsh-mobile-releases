## 已实现的功能

- 中文原生界面、真实引擎对话、会话管理、任务队列及逐次工具确认。
- 文件文字提取、中文图片与扫描件识字、办公资料导入、结果保存与分享。
- 手机应用允许名单与无障碍操作、通知读取和逐次确认回复、定时任务。
- Termux 兼容环境中的手机本地引擎管理、SSH 加密隧道、连接诊断与应用内更新。
- 新增第三方 DSHarness Remote 的中文账号授权、固定主机身份、原生加密对话、停止及历史和草稿恢复。

实际对话需要运行本机或远程引擎，并配置用户自己的模型网络接口与账号。本机引擎目前需要 Termux，没有本地离线大模型。原生加密远程入口提供文字对话与工具确认；资料助手、手机操作、通知和定时任务通过本项目的手机连接服务使用。第三方远程服务来自社区项目，不是 DeepSeek 官方提供的远程服务。

## 更新与验证

已有固定签名版本可在「设置 → 应用更新」检查新版本，按系统提示覆盖安装并保留数据。已经安装的手机本地引擎请先停止，再点击「修复或更新引擎」同步组件。早期 0.1.0、0.1.1 使用临时签名，首次换成固定签名版本时需要卸载旧版；卸载前请自行保存需要的数据。

0.9.0 已通过 24 项主机测试、58 项安卓单元测试和安卓十、十五的 116 项行为检查。公开安装包与更新信息已匿名下载核对，安装包摘要和固定签名一致。自动联调使用真实引擎和本地模拟模型接口；荣耀 80 GT 真机、真实模型账号和实际公网部署仍需要使用环境验证。

免 Termux 的内置引擎、点对点远程直连、远程终端与文件浏览、第三方插件市场、声音模型、加密在线分享、第三方账号网页登录或扫码授权，以及独立显示操作尚未实现。
